# SCMR 传输选择与只读绑定

绑定成功证明接口存在，不代表有创建或修改服务的权限。地址、端口、来源和传输约束来自本次输入。

## 选择方法

- 已知 SMB 端点：打开 `svcctl` 并绑定 SCMR；库支持显式端口时使用输入端口。
- 已知直接 RPC/TCP 端点：使用 `ncacn_ip_tcp` 连接该端点并绑定同一接口。
- 未给出端点、允许服务发现：向目标端点映射器查询 SCMR 对应 TCP 端点，再验证实际绑定；映射记录本身不能替代绑定响应。
- 输入限定端口但传输未知：先做该端点的有限协议识别；不能换到别的端口后报告原条件通过。
- 当前工具无法表达指定传输或端口：换支持的方法；仍缺少条件则记未知。

## 最小绑定

- 接口 UUID `367ABB81-9844-35F1-AD32-98F038001003`，版本 2.0。
- 只做 bind，不创建、启动、停止服务，也不修改配置。
- 优先使用现有库/客户端的一条**短调用**；不要把示例脚本、字节数组或整段协议报文复制进请求 `content`。
- 成功证据：`bind_ack`（`RPC_PDU_TYPE=12`）、`RESULT_COUNT=1`、`CONTEXT_RESULT=0`；SMB 路径同时保留目标 445 的 `ESTABLISHED`。
- 分片未处理、回复截断、认证拒绝、仅端口开放，都不算绑定成功。

## 示例（只示意，不要求逐字复制）

```text
使用执行面已有的 SMB/RPC 库：连接输入端点，绑定上面的 UUID，读取 bind_ack，然后断开。
content 只放这一条最小调用；不要内嵌字节数组。
```

## 判据

- 目标、传输约束及 SCMR 接口绑定接受均得到证据：通过。
- 仅端口开放、SMB 协商成功、本地服务列表或通用 RPC 响应：不足，未知。
- 客户端缺失、传输超时、访问拒绝、回复不完整：未知，反馈具体阶段与原始错误后调整方法。
- 可明确归因于该目标通道的连接拒绝，或完整 RPC 响应明确不提供指定接口：不通过。

本技能不查询 `Get-Service -Name scm`，不以 `RpcSs` 进程/服务正在运行代替远程接口绑定。执行载体由外部提供。
