# 报告的最小口径（v0.3）

从 [三表契约](runtime_data_contract.md) 读取结果，不重跑工具或用新模型重新裁判。

报告只回答：

1. 哪个图、哪次 run、使用什么实验条件和配置？
2. 全部 AND 中，哪些成功、反证、阻塞、证据不足，哪些尚未完成？
3. 每个节点依据哪些 records，原始工具输出在哪里？
4. 终点 OR 是否已有成功 provider；其他分支是否遗漏？
5. MSF 会话准备是否成功，对后续资源有什么影响？
6. 依赖违反、重复/遗漏、检查结果复现、模型/工具调用成本是多少？

分母只取原图 AND。succeeded/failed/blocked/uncertain 算本轮结案；pending/running 不算完成。
终点 OR 单列，不算一次执行。会话失败不改写节点成功率。
finished 只表示工作已结案，图是否全部成功另列统计，不增加整体八态结果。
records.id 用于排序和证据引用，缺失输出写明缺口。当前事实的来源和图参数不再复制成另一份报告数据库。
